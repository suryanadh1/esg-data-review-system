## ESG Domain Knowledge

**What is ESG?**  
Environmental, Social, and Governance criteria are a set of standards for
a company's behaviour used by investors.

- ESG Framework Overview: https://www.msci.com/our-solutions/esg-investing
- GRI Standards (Global Reporting Initiative): https://www.globalreporting.org/standards
- CDP Disclosure Framework: https://www.cdp.net

**Typical ESG Metrics**:  
Reference: S&P Global ESG Scores Methodology  
https://www.spglobal.com/esg/solutions/data-intelligence-esg-scores
